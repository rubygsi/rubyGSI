About rubyGSI

rubyGSI is a repository dedicated to providing custom GSI (Generic System Image) builds. Our goal is to offer a unified place to download pre-built images that work on a wide range of Android devices with Project Treble support (arm64).

We do not focus on a single brand or OS. Instead, we collect and build images from multiple sources, making it easier for users to find a GSI that suits their needs.

What is a GSI?

A Generic System Image (GSI) is a universal Android system image that can be flashed onto any device supporting Project Treble. It allows you to run a different version of Android without needing a device-specific build.

Our GSIs are built using MysticGSI, a powerful tool that converts stock firmware into a GSI-compatible image.
